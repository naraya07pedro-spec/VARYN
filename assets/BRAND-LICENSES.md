# Bundled third-party application icons (Alpha 10)

These images are curated **authentic brand artwork from existing open-source icon projects**, not AI-generated illustrations or VARYN's own trademarks. All are provided for accurate product identification, not to imply sponsorship, partnership, official authorization, or any existing app login. Logos and brand names remain trademarks of their respective owners.

All original SVG sources are stored at `assets/brand_svg/`; build automation rasterizes them into 48×48 PNGs inside the Windows portable application. No icon CDN or user tracking request is made at runtime.
