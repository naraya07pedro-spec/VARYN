# VARYN 17S-41 | Provider Readiness + Metadata-Only Acceptance Evidence

**Scope and owner policy (2026-11-06 WIB):** Original strategy B: model API execution is permitted as a separate opt-in auxiliary ability; original Option C official **consumer** ChatGPT, Claude, Gemini automatic bidirectional account histories/memories remains **BLOCKED / no verified official write/read interfaces**. This checkpoint provides owner-PC readiness and reviewable local evidence without requesting the owner's secrets and without claiming a real API provider has responded.

## What the owner can do in the GUI

- Open **17S-40 Model Control Center** (main VARYN Tk window; Windows Portable also includes the UI).
- Register an exact model/provider ID and manually verified, dated input/output price per 1 million tokens. This is a USER ASSERTION, not verified pricing, a quota guarantee or a billing hard cap. The 9Router localhost endpoint is not itself proof of an authorized upstream provider.
- Press **17S-41 | Check readiness (NO network)**. The check uses only currently registered, dated quote; this window's network toggle; the independent desktop gateway capability; 9Router upstream-use authorization; and whether its required **OS environment variable is nonempty**. It does **not print, save, hash, transmit, or otherwise display the actual key**, open sockets, or make any model requests. Reports **READY FOR ONE OWNER-APPROVED ATTEMPT** at best. It does not assert account validity, actual model availability, endpoint reachability or price authenticity. Expected variable names: `OPENROUTER_API_KEY`, `DEEPSEEK_API_KEY`, `VARYN_9ROUTER_API_KEY`.
- The existing **Review exact request & send ONCE** still shows the exact `SYNTHETIC:` test request in an approval modal. Denial causes zero dispatch and zero quota reservation. After affirmative approval, one API attempt can take place only with the previous network/upstream credentials and quota checks; no automatic retry, no fallback at the VARYN layer.
- After a successfully **parsed response from a non-FAKE gateway request without a test transport override**, button **17S-41 | Review & save content-free receipt** is enabled. It shows a NEW-FILE-ONLY JSON receipt and requires the owner's exact metadata review, approval, and choice of a new `.json` file path. `O_EXCL` refuses overwrites, also with `O_NOFOLLOW` where supported. No automatic writing or saving. No plaintext task, returned answer, private note, API key, credential, session ID, or environment value is written. This file contains only local observation time, selected provider/model, optional **UNVERIFIED provider-reported model label**, mismatch flag, locally estimated micro-USD cost, self-reported token counters (when provided), and explicit FALSE for all authentication, native history sync, account identity and actual-billing claims. Files are metadata-only **not encrypted**; a Windows account may expose them to other same-user processes. Fake mode never produces a receipt.
- After a reply the GUI distinguishes `selected_model` from the `provider_reported_model`, including an explicit mismatch warning. The reply's `ModelReply.model` remains the model that VARYN REQUESTED; the reported model label is untrusted response metadata, not a verified actual upstream model.

## Transport and security improvements

- `varyn/gateway_chat.py` now forces `ProxyHandler({})` for **9Router loopback** traffic so `HTTP_PROXY` and `HTTPS_PROXY` environment variables cannot silently relay localhost bearer credentials to a configured proxy. Still only the pinned default `http://127.0.0.1:20128/v1/chat/completions` when not in tests. No HTTP redirects. Remote OpenRouter and DeepSeek HTTPS use user OS proxy configuration; proxy trust must be assessed by the owner.
- `varyn/universal_gateway.py` preserves network-OFF / per-request review / env key / upstream approval / in-memory budget and exposes sanitized provider-CLAIMED model metadata and possible mismatch, never authenticated provider origin.
- No automatic migration of app memories, no consumer cookies/OAuth extraction, no direct official account-history writing, no silent model switch at the VARYN layer. **Both OpenRouter and 9Router can have their OWN internal upstream provider routing and fallback**; an owner-entered `route_fixed` claim does not prove that the upstream inference provider is fixed. OpenRouter documents provider-level rerouting explicitly.

## CI evidence and limitations

- `tests/test_provider_readiness.py` on Windows/Ubuntu: strict offline key-presence-only preflight, stale/missing quote and permission checks, fake never live, accepted/rejected metadata receipt constraints, no secret/task/output in JSON, no overwrite, tainted reported model rejection and a **real TCP loopback HTTP POST** against a **controlled local stub server** with fictional token and intentionally hostile `HTTP_PROXY`. This tests the HTTP wire and redirect/proxy policy but is **NOT a real 9Router application, authenticated provider account or outbound API billing test**.
- `tests/test_provider_readiness_tk.py` native Windows hosted Tk: real user controls for missing/present env key, no-network readiness, consented single mock response, source-label mismatch, denied owner save, separately approved new JSON file save, no-overwrite, FAKE never produces real-provider receipt. This is CI-driven button invocation, **not human owner acceptance on the owner's PC**.
- Existing full Windows+Ubuntu test suites and frozen Windows unsigned EXE smoke, SHA256 manifest and separate DPAPI restart checks remain mandatory. The frozen portable smoke constructs the Model Control Center but does **not** prove real account connectivity or actual billing. New metadata receipt is not automatically uploaded to GitHub or the user's chats; the owner chooses its location manually.
- Provider prices, dynamic model names, free tiers and account-specific rate limits change. **Do not** interpret VARYN estimates or success flags as a billing cap or guaranteed available model. A failed/uncertain API request may consume local budget and might consume upstream credits.
