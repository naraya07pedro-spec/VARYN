## Reporting method

Check GitHub repository stars/forks/issues from https://github.com/naraya07pedro-spec/VARYN and Releases from https://github.com/naraya07pedro-spec/VARYN/releases. Note exact dates for each snapshot, without suggesting Github stars imply adoption. Track actual independent testers separately via permissioned, anonymized issue references. Do **not** collect private conversations, IP addresses, API keys, or invisible telemetry.

Useful early goals to **measure**, not guarantees: 25 organic stars, 5 independent testers and 2 actionable technical feedback reports. Hiring signal comes from reproducible shipped behavior and thoughtful fixes, not purchased stars or fake engagement.

Current public code is still on draft PR #1; published adoption claims should reflect which revision and branch an outsider could actually download.
