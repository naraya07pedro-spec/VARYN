# VARYN 17S-39 | Universal Model Gateway and fixed-endpoint provider registry

Date: 2026-11-05. Owner-approved strategy **B**: original Option C remains the long-run goal of supported automatic bidirectional **official consumer-app** history/memory synchronization, while strictly separated semi-automatic official handoffs and approved model API capabilities are permitted as additional tools. The user clarified VARYN is a **many-model** personal harness, not just ChatGPT/Claude/Gemini. This checkpoint adds an independently executable model routing layer without treating consumer login as an API credential.

## Delivered functional code
- `varyn/model_registry.py` provides immutable, typed `Offer` entries for explicit `openrouter`, `deepseek`, loopback `9router`, and offline `fake`. A model may enter deterministic least-estimated-price routing only if it is **enabled**, `route_fixed`, `owner_reviewed`, has **both input and output prices explicitly supplied**, and carries a price date no older than 30 days. An unknown price or unreviewed/free-looking offer does **not** qualify. Tie-breaks are deterministic by cost, provider, model. Specific provider selection is supported. Model aliases allow `/` and `:` but reject traversal-like or control characters. CI uses exclusively **fictional** prices.
- `varyn/gateway_chat.py` implements OpenAI-compatible **non-streaming chat completions** for three pinned endpoints: `https://openrouter.ai/api/v1/chat/completions`, `https://api.deepseek.com/chat/completions`, `http://127.0.0.1:20128/v1/chat/completions`. No arbitrary host override and no credentials in URLs. Requests reject HTTP redirects; response bytes and text are bounded; a single completed plain-text answer is required. Tool calls, partial results and ambiguous multi-choice replies are refused. Environment keys: `OPENROUTER_API_KEY`, `DEEPSEEK_API_KEY`, `VARYN_9ROUTER_API_KEY`. Never put keys in source code, docs, screenshots or commit.
- `varyn/universal_gateway.py` links the cost registry, fixed wire adapter, and existing in-memory `UsageBudget`. **Network OFF by default**; each new live request needs explicit `approve_request=True`, a configured environment key, and budget reservation before dispatch. **9Router local** also requires explicit `authorized_upstream=True` because its internal routing may involve subscription credentials and provider-dependent fallback. The gateway does **not** itself retry or fallback; an upstream router **may independently** fallback. No automatic export of local memory or provider account history.
- `python -m varyn.model_registry` runs a deterministic local **FAKE**, zero-network, synthetic-price CLI demonstration without an account, credit, or API key. The Python gateway supports real API calls only when explicitly enabled and all gates pass. It is not yet connected to the main Tk GUI and the current 17S-39 automated tests do **not** contact remote providers.
- `tests/test_universal_gateway.py` tests audited prices and model IDs, fixed URLs, malformed completion and forbidden tool calls, nonredirect auth, default offline network, missing key, fresh owner approval, 9Router upstream-specific authorization, local reservations, generic sanitized transport failures and no implicit fallback. CI adds explicit 17S-39 test step on Windows and Ubuntu before full regression.

## Risks, limitations, and truthful product scope
**Pricing:** price inputs and `owner_reviewed` are local operator assertions, not independently verifiable evidence of current provider billing. An estimate derived from token guesses is **not a hard monetary spending cap**, and a nominally free route is **not** unlimited or guaranteed available. Price/availability varies by provider/account. A `route_fixed` boolean is operator-supplied; with 9Router it must not be used to claim the *upstream* provider route is immutable. Its own internal fallback may change actual cost/provider. Never silently retry a paid request because first-attempt charges can remain unknown.

**Privacy and credentials:** the pilot only permits explicitly tagged fictional `SYNTHETIC:` tasks, with existing heuristic secret scanning. This is not comprehensive personal-data detection. Environment keys are read only at requested dispatch and never stored in VARYN's databases; requests and responses are not logged by this gateway. Local 9Router dashboard/API must not be publicly exposed. Upstream terms, subscription redistribution rules, user login, tool permissions and endpoint availability require separate verification by the owner. Free accounts may have strict and changing quotas. Current `UsageBudget` is memory-only and resets on process restart; it does **not** enforce a global spend ceiling.

**Acceptance gates still outstanding:** live calls with legitimate owner API credentials, actual Windows owner-PC UI, continuously refreshed model catalog, audited provider free quotas/prices, account-specific policy review, production retry policies with idempotency/uncertain billing, persistent spend ledger, and a final desktop user interface for choosing/routing models. The frozen Windows portable EXE packaging checks import/startup and preexisting synthetic DPAPI flows but do not demonstrate a full live routing session. Option C official consumer-app native automatic bidirectional sync remains BLOCKED/unverified.
